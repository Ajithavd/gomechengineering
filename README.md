# Go Mech Engineering Website

Corporate website for Go Mech Engineering, a leading precision engineering and industrial manufacturing company based in Chennai.

## Technologies Used

- **Framework**: React with Vite
- **Styling**: Tailwind CSS
- **Components**: Shadcn/ui
- **Animation**: Framer Motion
- **Language**: TypeScript

## Project Setup

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build the production application:
   ```bash
   npm run build
   ```

4. Preview the production build locally:
   ```bash
   npm run preview
   ```
